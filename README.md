# Mundo Bloco — site sobre Minecraft

## Sobre
Site de fã feito como atividade da unidade curricular de
Programação de Aplicativos, turma DS25 M3.


## Páginas
- index.html — página inicial
- sobre.html — história, modos de jogo e glossário
- dados.html — tabela de mobs
- cadastro.html — inscrição no campeonato
- contato.html — contato e formulário de mensagem

## Tecnologia
HTML

## Como executar
Baixe a pasta e abra o arquivo index.html no navegador

## Imagens
Todas as imagens são capturas feitas por mim no jogo

## Validação das páginas
As cinco páginas passam no Nu HTML Checker sem erros.
O Lighthouse de acessibilidade marcou 100 nas cinco páginas
