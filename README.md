# Mundo do Bloco: site sobre Minecraft

## Sobre
Site feito como atividade da unidade curricular de Programação de Aplicativos para testar os conhecimentos de HTML.

## Páginas
- index.html - página inicial
- sobre.html - história, modos de jogo e glossário
- dados.html - tabela de mobs
- cadastro.html - inscrição no campeonato
- contato.html - contato e formulário de mensagem

## Tecnologia
HTML

## Como executar
Abra a pasta e abra o arquivo index.html no navegador

## Imagens
Todas as imagens são capturas feitas por mim no jogo

## Validação
As cinco páginas passam no HTML Checker sem erros
O Lighthouse de acessibilidade marcou entre 95-96 em todas as paginas
